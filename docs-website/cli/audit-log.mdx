The `npx wgc audit-log` commands manage the organization's [audit log](/studio/audit-log). They require an organization admin.

## Stream

`npx wgc audit-log stream` configures where audit logs are streamed. An organization has at most one destination. Splunk HTTP Event Collector (HEC) is the only one supported for now.
