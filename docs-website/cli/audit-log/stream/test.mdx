## Usage

```bash
npx wgc audit-log stream test
```

## Description

The `npx wgc audit-log stream test` command sends a single test event to the configured collector. If the collector rejects it, the command fails and prints the collector's response, e.g. `Collector responded with 403: Invalid token`.

Run it after `npx wgc audit-log stream set splunk` to check the endpoint, token and index.

## Examples

```bash
npx wgc audit-log stream test
```
