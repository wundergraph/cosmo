## Usage

```bash
npx wgc audit-log stream delete
```

## Description

The `npx wgc audit-log stream delete` command stops streaming the organization's audit logs and removes the configuration, including the stored URL and token. To pause the stream and keep the configuration, run [`npx wgc audit-log stream set splunk-hec`](/cli/audit-log/stream/set-splunk-hec) with `--disabled` instead, repeating `--endpoint` and any `--index`, `--source` and `--sourcetype` you want to keep.

## Examples

```bash
npx wgc audit-log stream delete
```
