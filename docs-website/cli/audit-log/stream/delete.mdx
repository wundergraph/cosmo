## Usage

```bash
npx wgc audit-log stream delete
```

## Description

The `npx wgc audit-log stream delete` command stops streaming the organization's audit logs and removes the configuration, including the stored URL and token. To pause the stream and keep the configuration, use `npx wgc audit-log stream set splunk --disabled` instead.

## Examples

```bash
npx wgc audit-log stream delete
```
