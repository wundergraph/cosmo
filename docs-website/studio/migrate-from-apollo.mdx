If you have graphs in Apollo GraphOS, you can migrate them to WunderGraph Cosmo from Studio.

On the graphs page, click "Create" and select the "Migrate from Apollo" tab. If the organization has no graphs yet, the graphs page also links to it.

The form asks for the "Graph API Key" of the federated graph to migrate and the name of the variant.

<Info>
  Your API key is never saved nor stored; it is only temporarily used to fetch the necessary data for migration.
</Info>

Paste the key into the "Graph API Key" input. Enter the variant to migrate in the "Graph Variant Name" input. Click "Migrate Graph".

Cosmo creates the federated graph and its subgraphs, then shows a graph API token with the command to run the router. The token is shown once, so store it safely. You can generate new router tokens later from the graph's overview page.
